# 生産統計のデータ

`/weekly-reports/production` は `lib/reports/data/production.json` の公表値を表示する。

- 農業総産出額：e-Stat「年次別農業総産出額及び生産農業所得」全国累年Excel。1975～2024年、原単位は億円。米（D列）、野菜小計（I列）、畜産計（Q列）を採用し、その他＝総額－3部門。1975年は沖縄県を含まない。
- 食料自給率：農林水産省「総合食料自給率（カロリー・生産額）、品目別自給率等」Excelの供給熱量ベースの総合食料自給率。1975～2025年度、2025年度は概算。農業産出額の暦年と同じ年の位置に年度値を置く。2025年の棒は欠測のままにする。
- 工業生産：2024年度国民経済計算（2020年基準・2008SNA）の主要系列表「経済活動別国内総生産（名目）」Excel「実数」シート。鉱業・製造業・建設業、1994～2024暦年、原単位は10億円。表示は兆円。指定の2025年12月23日公表PDFは構成比のため、その丸め値から金額を逆算しない。公式Excelの取得時点の改定値を採用。旧基準との接続は行わない。

データの再取得（Python、openpyxl・xlrdが必要）：

```powershell
python scripts/import-production.py
```

保存済みの公式Excelを再解析する場合：

```powershell
python scripts/import-production.py --source-dir tmp/production-sources
```

取得日時・各ファイルのURL・SHA-256をJSONに保存する。表構造・単位・連続年次を取り込み時に検証する。表の更新でURLや構造が変わった場合はスクリプトの出典定義・検証を確認する。定期取得のLambdaには未接続で、更新はこのスクリプトで行う。
