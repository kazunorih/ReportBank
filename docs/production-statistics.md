# 生産統計のデータ

## FIGURE03-3：品目別生産統計

対象は2007～2025暦年。経済産業省生産動態統計年報の全分野から、生産金額の公表数値を採用する。鉄鋼・化学・繊維等を販売金額や生産数量から推計しない。原資料の千円は1,000で割って百万円に統一し、画面では百万円を1,000,000で割り兆円にする。車種は指定に沿って乗用車3区分、トラック3区分、二輪自動車の排気量区分を集約。けん引車・特殊車・トレーラ・車体・部品は別品目。化粧品は全国生産額のみ採用する。

旧Excelは日時セル・CY表記から暦年行を判別し、FY・四半期・月次を除く。生産金額列を対象に、品目番号が範囲で示された親分類集計を除外。印刷の製品別と方式別、化粧品の全国と地域別を重複加算しない。2021～2023年は年計列、年計掲載のない2024～2025年は12か月の月額を合計する。秘匿X・不詳***・未公表等をゼロで補完しない。部分公表の集約品目は公表分と明記する。

2025年の公表数値を比較できる上位10品目を全期間で固定し、それ以外の公表数値は「その他」。旧分類と対応しない品目は未収録として表示し、その年に取得できる別名品目はその他に含まれる。年により調査品目・単位・対象範囲が異なるため、厳密な同一範囲の成長率比較には使わない。棒全体は公表生産金額を集計したもので、工業全体の総生産額・GDPではない。

原資料の公式配布URL・SHA-256・様式を `lib/reports/data/product-production-sources.json` に保存する。資料は経産省サイトの403エラーのためe-Statの同一年報を利用。元ファイルは `tmp/meti-seidou/<statInfId>.xls` に保存（拡張子と異なり新年報はxlsx形式）。再取得時にSHA-256不一致ならレビュー前に停止する。データは `lib/reports/data/product-production.json`。各年の分類別公表額・部分公表分類・数値確認件数・欠測件数・採用資料IDを保持。

```powershell
python scripts/import-product-production.py --source-dir tmp/meti-seidou
python -m unittest discover -s scripts -p test_product_production.py
```

読み取りにopenpyxl・xlrdが必要。元Excelへの書き込みは行わない。公表数値の合計・表示10品目＋その他・連続19年・単位・車種統合を照合する。

## FIGURE01：日本のGDP推移

名目GDPは1994～2024年を産業別積み上げ、2025年は総額のみを単色の棒で表示する。実質GDP総額は1994～2025年の折れ線（2020暦年連鎖価格）。共通の金額軸を使う。2025年の産業別内訳を0や「その他」として補完しない。

追加の総額データは `lib/reports/data/gdp-totals.json`。内閣府の2026年4–6月期2次速報（2026-09-08公表）の「名目暦年」「実質暦年」CSVのGDP（支出側）列を使用する。年度データ・四半期の年率換算値・成長率と混同しない。2025暦年は名目666,440.7、実質593,689.9（原単位：10億円）。表示は1,000で割って兆円に換算する。各CSVのURL・SHA-256・取得日時を保持する。既存の2024年までの名目産業別内訳は改訂せず、速報系列との改訂時点の違いを画面に注記する。

```powershell
python scripts/import-gdp-totals.py
python -m unittest discover -s scripts -p 'test_gdp*.py'
```

保存済みCSVを再解析する場合は `--source-dir tmp/gdp-totals` を指定する。選択した公表回を固定して再現性を確保する。更新時はスクリプトの公表回・ファイル名・期待期間・照合テストを合わせて見直す。

`lib/reports/data/gdp.json` はFIGURE03と同じ公式Excelの「実数」シートを使用する。1994～2024暦年（31年）、2020年基準・2008SNA。16産業の大分類のうち「その他のサービス」を除いて最新年（2024年）の金額上位10産業を選び、全期間で分類と順序を固定する。製造業の内訳などの下位分類を重ねて加算しない。残り6産業（農林水産業・その他のサービスを含む）は「その他」。棒の合計を原表の「国内総生産」に一致させるため、その他はGDP総額－上位10産業とし、輸入品に課される税・関税、総資本形成に係る消費税の控除、統計上の不突合、丸め差も含める。原単位は10億円、表示単位は兆円。

```powershell
python scripts/import-gdp.py --source-dir tmp/production-sources
python -m unittest discover -s scripts -p test_gdp.py
```

標準ライブラリのみ使用。`--source-dir` を省略すると公式Excelをダウンロードする。FIGURE03の保存済みSHA-256と一致する資料だけ採用し、資料取得日はFIGURE03と共通、処理日は別に保存する。公式Excelが改訂された場合は先に `import-production.py` でFIGURE03を更新する。16産業の小計・税等調整後のGDP・連続年次・FIGURE03の観測値との一致を検証してからJSONを保存する。

`/weekly-reports/production` は `lib/reports/data/production.json` の公表値を表示する。

- 農業総産出額：e-Stat「年次別農業総産出額及び生産農業所得」全国累年Excel。1975～2024年、原単位は億円。米（D列）、野菜小計（I列）、畜産計（Q列）を採用し、その他＝総額－3部門。1975年は沖縄県を含まない。
- 食料自給率：農林水産省「総合食料自給率（カロリー・生産額）、品目別自給率等」Excelの供給熱量ベースの総合食料自給率。1975～2025年度、2025年度は概算。農業産出額の暦年と同じ年の位置に年度値を置く。2025年の棒は欠測のままにする。
- 工業生産：2024年度国民経済計算（2020年基準・2008SNA）の主要系列表「経済活動別国内総生産（名目）」Excel「実数」シート。鉱業・製造業・建設業、1994～2024暦年、原単位は10億円。表示は兆円。指定の2025年12月23日公表PDFは構成比のため、その丸め値から金額を逆算しない。公式Excelの取得時点の改定値を採用。旧基準との接続は行わない。

データの再取得（Python、openpyxl・xlrdが必要）：

```powershell
python scripts/import-production.py
```

保存済みの公式Excelを再解析する場合：

```powershell
python scripts/import-production.py --source-dir tmp/production-sources
```

取得日時・各ファイルのURL・SHA-256をJSONに保存する。表構造・単位・連続年次を取り込み時に検証する。表の更新でURLや構造が変わった場合はスクリプトの出典定義・検証を確認する。定期取得のLambdaには未接続で、更新はこのスクリプトで行う。

## FIGURE03-1：産業機械受注

FIGURE03「工業生産」を読み解く参考統計として、2020～2025年の暦年（1～12月合計）と2026年1～8月（8か月分）を表示する。月次グラフ・月別数値表は掲載しない。`lib/reports/machinery-orders.ts` で各期間の月が重複なく揃っていることと加算整合性を検証してから、百万円の整数で集計する。グラフ・数値表は100で割って億円に換算。2026年は横軸・数値表に8か月分と明示し、通年値と区別する。内需と輸出（外需）の2系列を積み上げる。原データと再取得スクリプトは月次のまま保持し、各年の採用資料へのリンクを年別数値表に掲載する。2019年は表示対象外。受注額はGDPに加算できる産業別付加価値額ではない。

## FIGURE03-2：建設機械出荷

日本建設機械工業会の「建設機械出荷金額統計（内需、外需）」Excelを使用。1995～2025年は1～12月、2026年は1～9月（9か月分）。年度累計X列ではなく、同年1～12月のC～N列を集計し、暦年累計W列と照合する。原単位は百万円、画面は億円。国内・輸出の合計で、補給部品を含む総合計を使用する。取得URL・SHA-256・取得日を `lib/reports/data/construction-machinery.json` に保存。

分類名を正規化し、油圧ショベル・ミニショベルを合算する（過去資料でミニショベルは途中から独立分類）。空欄は国内・輸出の加算と総合計で整合性を確認。2025年の通年額を基準に、油圧ショベル・ミニショベル、補給部品、トラクタ、建設用クレーン、道路機械を表示。原表のその他建設機械を含む残余は「その他」。本体合計・総合計を分類に重ねて加算しない。最新年は対象月数を横軸と数値表に明示。棒の上には期間合計額を億円・小数第1位まで表示する。出荷額はGDPの付加価値額とは異なる参考統計。

```powershell
python scripts/import-construction-machinery.py
python -m unittest discover -s scripts -p test_construction_machinery.py
```

公式ページのリンクを再取得し、Excelは `tmp/cema` にキャッシュする。更新の際は新しい `--source-dir` を指定する。連続年、歴史年の12か月完備、国内＋輸出＝機種別小計、分類別合計＝総合計、月額合計＝暦年累計を検証し、不整合時はJSON更新前に停止する。

`lib/reports/data/machinery-orders.json` を使用。日本産業機械工業会の統計資料ページに掲載された「産業機械受注状況」PDFの表1から、内需計・外需・総額を月次で取得する。別統計の「産業機械輸出契約」「産業機械輸出入実績」は使用しない。「輸出（外需）」は海外からの受注を意味する。

2021年4月資料の表1に含まれる2019年4月から、2026年8月まで89か月を収録。掲載PDFを全件読み、重複月は新しい資料の値を優先する。原単位は百万円、グラフと数値表は100で割って億円に換算。季節調整前の月額を表示する。各月に採用資料の年月、各資料にURLとSHA-256、データ全体に取得日時を保存する。

再取得（Python、pdfplumberが必要）：

```powershell
python scripts/import-machinery-orders.py
```

PDFは既定で `tmp/machinery-orders` にキャッシュする。再ダウンロードする場合は `--source-dir` に新しいディレクトリを指定する。8部門の金額列、民需・内需・総額の加算整合性、各資料の最新月、全期間の連続性を検証し、不整合があればJSONの上書き前に停止する。既存の生産統計と同じく、定期更新のLambdaには未接続。
