# 生産統計のデータ

## FIGURE04：日本GDP推移

名目GDPは1994～2024年を産業別積み上げ、2025年は総額のみを単色の棒で表示する。実質GDP総額は1994～2025年の折れ線（2020暦年連鎖価格）。共通の金額軸を使う。2025年の産業別内訳を0や「その他」として補完しない。

追加の総額データは `lib/reports/data/gdp-totals.json`。内閣府の2026年4–6月期2次速報（2026-09-08公表）の「名目暦年」「実質暦年」CSVのGDP（支出側）列を使用する。年度データ・四半期の年率換算値・成長率と混同しない。2025暦年は名目666,440.7、実質593,689.9（原単位：10億円）。表示は1,000で割って兆円に換算する。各CSVのURL・SHA-256・取得日時を保持する。既存の2024年までの名目産業別内訳は改訂せず、速報系列との改訂時点の違いを画面に注記する。

```powershell
python scripts/import-gdp-totals.py
python -m unittest discover -s scripts -p 'test_gdp*.py'
```

保存済みCSVを再解析する場合は `--source-dir tmp/gdp-totals` を指定する。選択した公表回を固定して再現性を確保する。更新時はスクリプトの公表回・ファイル名・期待期間・照合テストを合わせて見直す。

`lib/reports/data/gdp.json` はFIGURE02と同じ公式Excelの「実数」シートを使用する。1994～2024暦年（31年）、2020年基準・2008SNA。16産業の大分類のうち「その他のサービス」を除いて最新年（2024年）の金額上位10産業を選び、全期間で分類と順序を固定する。製造業の内訳などの下位分類を重ねて加算しない。残り6産業（農林水産業・その他のサービスを含む）は「その他」。棒の合計を原表の「国内総生産」に一致させるため、その他はGDP総額－上位10産業とし、輸入品に課される税・関税、総資本形成に係る消費税の控除、統計上の不突合、丸め差も含める。原単位は10億円、表示単位は兆円。

```powershell
python scripts/import-gdp.py --source-dir tmp/production-sources
python -m unittest discover -s scripts -p test_gdp.py
```

標準ライブラリのみ使用。`--source-dir` を省略すると公式Excelをダウンロードする。FIGURE02の保存済みSHA-256と一致する資料だけ採用し、資料取得日はFIGURE02と共通、処理日は別に保存する。公式Excelが改訂された場合は先に `import-production.py` でFIGURE02を更新する。16産業の小計・税等調整後のGDP・連続年次・FIGURE02の観測値との一致を検証してからJSONを保存する。

`/weekly-reports/production` は `lib/reports/data/production.json` の公表値を表示する。

- 農業総産出額：e-Stat「年次別農業総産出額及び生産農業所得」全国累年Excel。1975～2024年、原単位は億円。米（D列）、野菜小計（I列）、畜産計（Q列）を採用し、その他＝総額－3部門。1975年は沖縄県を含まない。
- 食料自給率：農林水産省「総合食料自給率（カロリー・生産額）、品目別自給率等」Excelの供給熱量ベースの総合食料自給率。1975～2025年度、2025年度は概算。農業産出額の暦年と同じ年の位置に年度値を置く。2025年の棒は欠測のままにする。
- 工業生産：2024年度国民経済計算（2020年基準・2008SNA）の主要系列表「経済活動別国内総生産（名目）」Excel「実数」シート。鉱業・製造業・建設業、1994～2024暦年、原単位は10億円。表示は兆円。指定の2025年12月23日公表PDFは構成比のため、その丸め値から金額を逆算しない。公式Excelの取得時点の改定値を採用。旧基準との接続は行わない。

データの再取得（Python、openpyxl・xlrdが必要）：

```powershell
python scripts/import-production.py
```

保存済みの公式Excelを再解析する場合：

```powershell
python scripts/import-production.py --source-dir tmp/production-sources
```

取得日時・各ファイルのURL・SHA-256をJSONに保存する。表構造・単位・連続年次を取り込み時に検証する。表の更新でURLや構造が変わった場合はスクリプトの出典定義・検証を確認する。定期取得のLambdaには未接続で、更新はこのスクリプトで行う。

## FIGURE03：産業機械受注

`lib/reports/data/machinery-orders.json` を使用。日本産業機械工業会の統計資料ページに掲載された「産業機械受注状況」PDFの表1から、内需計・外需・総額を月次で取得する。別統計の「産業機械輸出契約」「産業機械輸出入実績」は使用しない。「輸出（外需）」は海外からの受注を意味する。

2021年4月資料の表1に含まれる2019年4月から、2026年8月まで89か月を収録。掲載PDFを全件読み、重複月は新しい資料の値を優先する。原単位は百万円、グラフと数値表は100で割って億円に換算。季節調整前の月額を表示する。各月に採用資料の年月、各資料にURLとSHA-256、データ全体に取得日時を保存する。

再取得（Python、pdfplumberが必要）：

```powershell
python scripts/import-machinery-orders.py
```

PDFは既定で `tmp/machinery-orders` にキャッシュする。再ダウンロードする場合は `--source-dir` に新しいディレクトリを指定する。8部門の金額列、民需・内需・総額の加算整合性、各資料の最新月、全期間の連続性を検証し、不整合があればJSONの上書き前に停止する。既存の生産統計と同じく、定期更新のLambdaには未接続。
